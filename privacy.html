Full Count Privacy Policy

Last updated: August 28, 2026

Overview

Full Count ("the App") is a mobile application that helps players and families track and visualize youth sports statistics. This policy explains what information the App collects, how it is used, and how it is stored.

Information We Collect

The App collects and stores the following information, either entered directly by the user or imported from box scores the user can see:

  • Player name (for players already tracked in GameChanger, the name originates from the user's GameChanger data and is imported into Full Count, where it is then stored independently)
  • Jersey number
  • Team name
  • Birth year
  • Game statistics (batting and pitching stats)
  • Player handedness (bats/throws right or left)
  • An optional player photo, if the user adds one

Imported box scores also include the names, jersey numbers, and game statistics of the other players in that game, on both teams, exactly as displayed publicly at the game and in GameChanger.

When a game is imported from screenshots, the images are read entirely on the user's device using Apple's built-in text recognition. The App stores the recognized text (names, numbers, and their positions on the page), never the screenshots themselves. The user's photos never leave their device and are not stored by the App.

When a game is imported from a PDF box score, the App keeps that PDF file with the game it created, so the game can be read again later without asking the user for the file a second time. It is stored the same way as the rest of the user's data, described under Data Storage and Sharing below.

Screenshots and PDF box scores may also be sent to the App from another app using the iOS share sheet. Files sent this way are written to the App's own storage on the user's device and stay there until the user imports or discards them. They are not transmitted anywhere while they wait. Once the game is imported, those copies are removed.

We do not collect email addresses, precise location data, government identification numbers, or payment information.

How Information Is Used

The information collected is used solely to provide the App's core features, including:

  • Displaying and organizing player and team statistics
  • Graphing statistical trends over time
  • Letting the user choose which statistics their views lead with
  • Verifying imported numbers against the box score's own totals

Data Storage and Sharing

Full Count uses Apple's CloudKit framework to store and, where applicable, sync data across a user's own devices. CloudKit is part of Apple's infrastructure and operates under Apple's own privacy and security practices.

Users may also choose to share a specific player's stats and profile with another user of the App using CloudKit sharing. This sharing is initiated and controlled by the user: the recipient can only see the specific player data that has been shared with them. The sharing user chooses each participant's access level when inviting them, either view only or view and edit, and may change a participant's access level, remove a participant, or revoke access entirely at any time within the App. When a shared player gains a new game, the App may show a notification on the sharing participants' devices; these notifications are generated locally on each device.

The App does not use third-party analytics, advertising, or tracking services. No data collected by the App is sold or shared with third parties for marketing or advertising purposes.

Children's Information

Because Full Count is designed for use in youth sports contexts, some information (such as a player's name, birth year, and statistics) may relate to a minor. This information is entered by a parent, coach, or other authorized user of the App, from information that is publicly displayed at the game and in GameChanger's box scores: either a PDF export (available to team administrators) or the user's own screenshots of the box score they can already see. All of it is used only for the statistical and organizational purposes described above, and it remains in the user's own iCloud unless the user explicitly shares a player.

Data Retention and Deletion

Users may delete player records and associated statistics within the App at any time. Deleting a record removes the associated data from the user's account. Revoking a CloudKit share removes the recipient's access to that shared data.

Changes to This Policy
